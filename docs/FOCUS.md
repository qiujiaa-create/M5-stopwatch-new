# Focus 本地专注计时

文档版本：0.1；最后更新：2026-09-17 18:45。

在 StopWatch 主固件的 Launcher 中打开 **Focus**。它提供本地正计时和固定 25 分钟倒计时，不连接 TickTick、Mac Bridge、Wi-Fi 或账号。Focus 内的 A/B 控制计时；退出 Focus 后，Codex 页面仍使用原来的 A/B 语音操作。

## 按键与触屏

| 当前状态 | A：正计时 | B：25 分钟倒计时 |
| --- | --- | --- |
| `READY` | 短按从 `00:00.0` 开始 | 短按从 `25:00` 开始 |
| `RUNNING` | 短按暂停正计时 | 短按暂停倒计时 |
| `PAUSED` | 短按从当前时间继续；长按归零到 `00:00.0` | 短按从剩余时间继续；长按重置到 `25:00` |
| `DONE` | 不适用 | 短按开始新一轮 25 分钟 |

长按使用手表按键驱动约 500 毫秒的阈值；复位仅对**对应计时器的 `PAUSED` 状态**生效。双击没有结束计时动作，两次短按按各自的开始、暂停或继续顺序处理。

页面上的 `A COUNT UP` 和 `B 25 MIN` 可切换查看模式；主按钮执行当前模式的开始、暂停或继续，`RESET` 只在当前模式暂停时显示。长按 A+B 返回 Launcher。切换模式标签只改变当前显示；启动另一种计时时，正在运行的计时会自动暂停。

## 显示与状态

- 正计时主数字显示分、秒，秒数右侧以较小字体显示十分之一秒；超过一小时后主数字改为时、分，右侧保留秒和十分之一秒。
- 倒计时固定从 `25:00` 开始，归零时显示 `DONE` 并振动一次。离开 Focus 页面后到点也会振动。
- 两个计时器的状态保存在手表运行内存中；离开页面或屏幕休眠不会清空，设备重启会清空。
- 页面以 466×466 圆形屏幕设计，界面标签使用当前固件可用的英文字体。
