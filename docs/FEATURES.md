## 两个固件，一个 Codex App

| 系统 | 启动槽 | 功能 | 切换 |
| --- | --- | --- | --- |
| StopWatch 主固件 | `factory` | Launcher、设置、Codex 页面、独立 Focus 计时、BLE HID、BLE 麦克风 | Launcher 或 Setup 的小智入口检查镜像后写入启动槽并重启 |

## Launcher 长按快捷启动

StopWatch 主固件的 Launcher 首页保留 A/B 短按左右切换图标，并增加独立的 1 秒长按快捷启动：默认长按 A 打开小智切换确认页，默认长按 B 打开 Focus。小智仍由原确认页检查 `ota_0` 镜像并等待用户确认，长按 A 本身不会写启动槽或重启。

在 `Settings → Device → Quick Launch` 中可分别设置 `Hold A` 与 `Hold B`。可选目标为 Disabled、Codex、Focus、Xiaozhi、Watch Face、Lucky Wheel、Maze 和 Settings；两个按键允许选择相同目标。设置保存在 `launcher` NVS 命名空间，关机后继续有效。未知或已经移除的持久化目标按 Disabled 处理，不能因 APP 安装顺序变化而打开错误程序。

A+B 组合操作优先于单键长按：单键按满 1 秒后锁定目标并按设置提供触觉反馈，松手后才打开 APP，避免仍按住的按键被目标 APP 继续处理；如果松手前形成 A+B，则取消本次单键快捷启动。两个按键完全松开后才接受下一次快捷启动。单键长按只执行一次，松手不会再产生短按翻页。

## Codex 页面

主固件 Codex App 只保留 `OpenWatcher V2`。旧 Codex Micro 页面和 `Setup → Device → Codex Theme` 已移除；不再读取历史主题设置，任何旧设置都直接显示 V2。原生 `Codex Micro` 输入模式独立于视觉主题，继续保留。

每次进入 StopWatch 主固件直接打开 Codex V2，跳过 Launcher 首屏构建、首次引导等待和 Launcher 开机音。A+B 退出后正常回到 Launcher，此时可打开 Focus、Settings 或小智确认页；返回 Launcher 不会自动再次进入 Codex。小智仍是独立启动槽，本改动不改写槽位选择。

V2 的首次触摸与手势轮询从空闲时 100 ms 缩短为约 33 ms，四 Agent 保留 280 ms 长按确认；中心 Radial 改为 200 ms 展开后短按方向、松手归中。按键仍由既有主循环处理，BLE 与麦克风就绪保护继续有效。轮询周期不代表端到端延迟，实际启动与操作响应需实机测量。

- **OpenWatcher V2**：周剩余额度、Today 消耗、独立 5H 剩余与重置时间；5H 横条内部连续由红、橙、黄向绿过渡，长度表示 5H 剩余。缺失、过期或越界只保留暗色轨道和 `--`，不借用周额度。最近四小时 24 格从左到右排列。
- 四个 90×78 px 的编号 Agent 卡片按浅 U 形排列，使用主机灯效表达执行中、未读、待处理、异常；离线、未知和其他灯色不伪造任务内容。短触取消，长按 280 ms 确认，同一触摸只提交一次；确认前滑动换目标重新计时。Working 使用边框呼吸并维持既有亮屏策略。
- 顶部为无文字的左右方向按钮，每个可见 84×34 px、采集 90×46 px，中间有 16 px 空隙。在原区域松手才旋转一次；拖动、跨区或移出取消，长按不连发。原生 Encoder 的用途仍取决于宿主 Knob 映射。小方向盘直径 88 px，长按 200 ms 展开居中的 304 px 圆形面板；松手后再点独立圆弧方向区，按下输出原生 Radial（距离 1）、松手归中，面板保留便于继续选择。× 在按下时即关闭，面板外同区松手关闭；拖动/跨方向会归中且不切换目标，语音或切页时收起。面板预建、方向反馈仅刷新对应按钮，减少显示锁占用。
- A/B、Typeless、微信及 Codex Micro 输入模式保持既有行为；录音波形显示在方向盘位置；停止录音即隐藏波形并恢复灰显方向盘，处理中保留顶部状态、禁止触摸，空闲后恢复操作。顶部文字显示连接、录音、处理中、录音中断或 `COMPACT SOON`；底部为左电池、右蓝牙两个图标，原四向提示文字和两个状态点已移除。电池框内只显示电量数字、无 `%`，两图标缩小/靠近/下移，避开 2/3 号卡片；≥30% 绿色、<30% 红色；蓝牙连接蓝色，断连红色加斜线。没有新增页面或切页手势。

显示按 466×466 圆屏设计，任务卡可见边界就是触摸边界，四角不超出圆屏；Agent 灯效是否已分配不作为发送门槛。源码与主机渲染不代表已安装或实机验收，详见 [表盘使用说明](CODEX_TASK_DECK.md)。

## Focus 本地专注计时

Launcher 的 Focus 应用提供 A 正计时和 B 倒计时，互斥运行。正计时显示到十分之一秒。倒计时默认 25 分钟，点击分钟数字可在 1–60 分钟间选择并保存；保存新时长会重置当前倒计时到待开始状态。在当前模式按另一按键只切换页面，进入目标页面后再按一次对应键才开始、暂停或继续；仅在 `PAUSED` 时长按对应键才复位。双击不触发结束动作；A+B 长按返回 Launcher。

正计时下方保留触屏主操作与暂停时的 `RESET`。倒计时模式右上角整块弧形半圆填充为 `#46D1E0`。倒计时下方改为带小喇叭图标的铃声点击按钮，不提供 B 的触屏开始、暂停、继续或复位；B 实体键保持这些控制。铃声默认关闭，开启时归零以最大提示音幅度播放约 4 秒；归零始终显示 `DONE` 并振动一次。时长和铃声开关保存在 NVS，运行计时仅在内存中，设备重启后重新初始化。Focus 不需要 TickTick 账号、Mac Bridge、Wi-Fi 或新的 BLE 协议；Codex 页面里的 A/B 语音操作仍按原状态机执行。操作表见 [Focus 使用说明](FOCUS.md)，安装和实机验证范围见 [项目状态](../PROJECT_STATE.md)。

## 三条独立链路

1. **标准 BLE HID**：A/B 和摇晃对应的系统按键；Bridge 退出后已配对的基本按键仍可工作。
2. **Codex Vendor HID**：原生 Agent、Encoder 与 Radial 事件；不以虚拟鼠标或键盘替代。
3. **BLE Companion 与麦克风**：Bridge 接收设备状态，推送额度/活动面板，控制按需音频；音频经虚拟设备交给 macOS 应用。

Typeless 默认 A 为 `F19`，B 短按和长按均在松开时发送一次配置的确认键（本机为 `Return`）；B 不再启动、停止或重试录音。录音或识别中按 B 可能提前发送，应先用 A 结束并等文字出现。微信输入模式继续使用原有确认和长按动作。`Codex Micro` 模式独立走 Vendor HID：A 为 Mic `ACT10`，B 松开为 Send `ACT12`。Bridge 支持输入配置、绑定同步、状态观察和可选的 Typeless 启动协调。改变按键行为需检查 V2 各输入模式及 Mac 端实际结果。

## 额度和活动

Bridge 可选读取本机 Codex 登录状态取得官方 usage 摘要，按 604800 秒周窗口与可选 18000 秒 5H 窗口分别推送。5H 缺失、过期或数值异常时显示 `--`，不换算成周额度或 0%。录音中面板推送暂存，回到空闲后再发送。Today 表示从北京时间 08:00 起的周额度百分点消耗，不是另一种官方日额度。最近四小时有 24 个 10 分钟格；可选云同步汇合多台 Mac 的统计。Wi-Fi panel fallback 在 StopWatch 主固件中默认关闭。详见 [额度说明](QUOTA.md) 与 [跨设备同步](stopwatch-cloud-sync.md)。

额度为被动显示，当前实现没有针对 5H 低额的声音或振动提醒。

## 音频发送和故障策略

StopWatch 麦克风按需唤醒，采集数据重采样至 16 kHz 单声道，按 20 ms 帧编码成 IMA-ADPCM，经 BLE Notify 实时传输。Bridge 解码 PCM 并固定输出到虚拟音频设备；不生成 WAV 或把录音上传到云端。虚拟设备已验证设置为 48 kHz。

启动前的就绪握手要求音频通知、按需采集及 Bridge 虚拟输出/路由健康。尚未就绪时设备短暂保留一次请求并显示 `MIC LINKING`；超时则中止。发送端在 NimBLE mbuf 不足时最多等待 80 ms，并为 HID、状态及订阅流量保留至少 4 个 mbuf；统计记录发送、丢帧及通知错误。Bridge 对短缺口填静音以保持时间位置，但明确断线或持续断流会中止当前听写并提示重新录制，不把缺失中段悄悄拼接成完整语音。详见 [BLE 麦克风](stopwatch-ble-microphone.md)。

Bridge v1.4.2 在停止/重建虚拟输出前先关闭回调入口并静音，待已进入的回调退出后再停止音频单元，避免同时查询与停止导致主线程卡住、额度和语音同步停滞。路由事件直接锁存静音，替换输出在回调外重新校验；保留转换前后设备校验与故障静音。`MIC LOST` 后连接恢复需按 A 重新录制，已中断的录音不自动续接。

## 验收边界

Bridge v1.4.2 已在本机安装并验证虚拟输出、连接/重连和定时额度推送；用户确认录音启动/停止、Codex Ready 和 5H 数值均恢复。长期稳定性与睡眠唤醒继续观察，详见项目状态。

输入延迟修复将额度背景与动态控件分层，并去掉未变化进度条的重复刷新；A/B 控制器、语音门控和音频/HID 协议保持更新前源码。主机采用与设备相同的局部刷新模式做回归，实际按键手感仍待复测。

2026-10-15 弧形任务卡已通过实际 LVGL 的主机渲染/触摸检查及固件构建；同日经用户授权已只刷入 factory，写后与独立校验通过，分区表和启动选择未变；Bridge/虚拟输出恢复，实际屏幕、触摸、按键和真实语音待验收。详见 [表盘使用说明](CODEX_TASK_DECK.md)。

源码存在、构建成功、镜像写入和设备最终操作是四种不同证据。Launcher 长按快捷启动已通过主机手势测试、ESP-IDF v5.5.4 构建并写入 factory；设置页圆屏布局、A/B 实际长按、短按不回归、配置重启保留及小智确认页仍需实机验证。2026-10-15 的 V2 单主题与开机直达镜像已构建、只刷入 factory 并通过独立校验；复位启动日志、BLE 与虚拟输出检查通过，实际屏幕和实体交互仍需用户验收。小智的当前启动槽、语音对话和切回操作也应单独验收。具体记录和下一步见 [PROJECT_STATE.md](../PROJECT_STATE.md)。

圆形四向面板采用石墨黑底、深灰圆弧与柔白箭头，按下显示深青底/青色箭头，无描边、阴影或发光。四段圆弧外半径 132 px、厚度 64 px、各跨 40°且两端圆润；方向触控在距中心 62–140 px 的四个 80° 扇区，角度间隙不触发方向，中央关闭触控半径 40 px。预览与实机验收边界见表盘使用说明和项目状态。
